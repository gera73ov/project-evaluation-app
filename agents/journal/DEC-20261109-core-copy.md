# DEC-20261109-core-copy

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-09T21:30:00Z
- **Трек:** CORE (CORE-023, CORE-024); потребители — FE-015 (копирование проекта), FE-027 (копирование
  ветки), QA-014
- **Основание:** SPEC FR-PRJ-02, FR-PRJ-03, 3.3, 3.4, BR-ROLE-06, Q-44, BR-TREE-05/06;
  contracts/openapi.yaml (`copyProject`, `copyBranchFrom`)

## Решение

1. **Имя копии** по умолчанию — «<имя> (копия)», обрезается так, чтобы уложиться в 200 символов;
   переданное имя обрезается по краям, минимум 3 символа.
2. **Что копируется в проект:** заказчик, описание, детализация, показатель КП, % РП (с обоснованием),
   длительность, срок (только если он не в прошлом — BR-PRJ-08), фазы, дисциплины с профилями, команда,
   локальные типы узлов, живое дерево (новые id, версия 1, без «Проверено»). Не копируются обсуждения,
   история узлов, снимки, корзина, «Результат пресейла» и журнал; в журнал копии пишется
   `project.created` с `copied_from`.
3. **Статусы веток копии:** «не нужно» остаётся; ветка, где есть узлы, — «черновик»; пустая —
   «не начата» (PLAN говорит «черновик»; пустая ветка остаётся «не начатой», как в новом проекте —
   толкование, первый узел переведёт её в «черновик»).
4. **Ставки, валюта, курс и НДС** копируются, только если копирующий — модератор исходного проекта;
   иначе у копии значения по умолчанию. Право `project.copy` требует системной роли «Модератор».
5. **Копирование ветки:** источник — узел другого проекта той же дисциплины, где пользователь сейчас
   участник (gate `branch.copy_from` с `as_source`, иначе 404). Ветка дисциплины копируется своими
   детьми, узел — с поддеревом; копии встают последними детьми выбранного узла. Лист с оценкой
   приёмником быть не может (422, BR-TREE-02).
6. **Типы при копировании ветки:** тип справочника сохраняется, если активен, иначе «Работа»; локальный
   тип источника переиспользуется по названию в приёмнике или создаётся там как предложенный.
7. **Лимиты** BR-TREE-05/06 проверяются до записи: при превышении 409 и ничего не копируется. В истории
   каждой копии — запись CREATE с `copied_from`; «Проверено» снимается с приёмника и предков,
   «готово» → «черновик».
