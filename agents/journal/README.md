# Журнал решений, инцидентов и ошибок агентов

Правила ведения — `AGENTS.md`, раздел 8; шаблон записи — `AGENTS.md`, приложение Г.

- Одна запись — один файл: `<ТИП>-<ГГГГММДД>-<трек>-<кратко>.md`, где `<ТИП>` — `DEC` (решение), `INC` (инцидент ИБ), `ERR` (ошибка процесса).
- Записи неизменяемы после слияния в `main`; исправление — новой записью с полем «Заменяет».
- Время — UTC, ISO 8601.
- Секретов, ПДн и реальных денежных данных в записях нет (`AGENTS.md`, раздел 6.3).
