# DEC-20261109-core-branch-status

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-09T16:10:00Z
- **Трек:** CORE (CORE-018, часть); потребители — FE-029, NTF-006, CORE-016, CORE-017, CORE-019
- **Основание:** SPEC 4.3, BR-BR-01…03, FR-NOTIF-01; contracts/openapi.yaml (`putBranchStatus`),
  notifications.yaml (`branch_back_to_draft`), errors.yaml; уточняет п. 8 DEC-20261109-core-node-edit

## Решение

1. **Ручные переходы** — только стрелки 4.3: «черновик» → «готово» (`branch.status.draft_done`),
   «не начато»/«черновик» → «не нужно» и «не нужно» → «не начато» (`branch.status.not_needed`). Вручную
   вернуть «готово» в «черновик» нельзя (на диаграмме это только автоматический переход); повтор того же
   статуса и прочие пары — 409 `INVALID_TRANSITION` с `from` и `to`.
2. **«Готово»** проверяет листья ветки (и саму ветку, если она лист, BR-TREE-04): «пусто» и «неверно» —
   409 `BRANCH_NOT_READY` с `node_ids`; лист 0–0–0 («ноль») готовности не мешает.
3. **«Не нужно»** — только у ветки без живых детей и без собственной оценки, иначе 409 `BRANCH_NOT_EMPTY`.
4. **Уведомление `branch_back_to_draft`** — модераторам проекта и экспертам дисциплины ветки, кроме автора
   правки (notifications.yaml), при каждом автоматическом сбросе «готово» → «черновик».
5. **Не сделано в этой части:** снятие «Проверено» по таблице BR-BR-02 — с CORE-019 (отметку ещё нельзя
   поставить); строки TC-BR-01 для удаления, восстановления, переноса, разбиения и сворачивания — с
   CORE-016 и CORE-017.
