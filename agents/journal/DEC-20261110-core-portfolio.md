# DEC-20261110-core-portfolio

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-10T13:10:00Z
- **Трек:** CORE (CORE-070, CORE-071); потребители — FE-050, EXP-010, QA-017 (TC-PORT-01, G-21)
- **Основание:** SPEC 3.3, 3.4, 10.4 (FR-PORT-01…03), 11.13, R-02, R-06, Q-31, GAP-05,
  SEC-AUTHZ-05; contracts/openapi.yaml «Руководитель пресейла», permissions.yaml
  (R-PRESALE-HEAD, M3.3-11/12), notifications.yaml `presale_head_joined`, audit-events.yaml

## Решение

1. **«Стать модератором проекта».** Строка команды «модератор» добавляется без проверки
   системной роли «Модератор» (R-06), повтор ничего не меняет. Аудит — `project.joined_as_moderator`
   и `project.team.changed` с `via: join_as_moderator`; журнал проекта, `member.updated`,
   пересчёт `no_moderator_since`. Уведомление `presale_head_joined` — активным модераторам проекта.
   «Архив» — 409 `PROJECT_STATUS_CONFLICT` (решает gate по каталогу прав).
2. **Ограничение после вступления.** В `PUT /projects/{id}/members` пользователь с ролью
   «Руководитель пресейла» без ролей «Модератор» и «Администратор» не добавляет и не снимает
   строки модераторов, кроме своей: 403 `FORBIDDEN`. Выйти сам может, если остаётся другой
   модератор (иначе 409 `LAST_MODERATOR`). Передача проекта — только реестр администратора.
3. **Реестр.** Все проекты, включая «Архив». Период — по дате создания в часовом поясе
   приложения, границы включительно. Порядок — от новых к старым, курсор — дата создания и id.
   «Дата изменения» — как в «Моих оценках»: позднее из правки проекта и журнала изменений.
4. **Сводка.** Фильтры сводки — только период (контракт `GET /portfolio/summary` принимает лишь
   `from`/`to`); остальные фильтры 11.13 №1 интерфейс применяет к реестру. Суммы
   `sum_won_cur`, `sum_lost_cur`, `sum_in_progress_cur` и доля выигранных в деньгах считаются в ₽
   без НДС (`quote_rub`): у проектов разные валюты КП, складывать их можно только в рублях
   (11.13 №6). «В работе» — «Подготовка», «Оценка», «Сведение». Медиана «договор / в КП» — в
   валюте КП (сумма договора хранится в ней, BR-PRJ-05), в процентах. Проценты и медианы — один
   знак, ROUND_HALF_UP. «Результаты по месяцам» — по месяцу создания, все месяцы периода, в том
   числе пустые. Проигрыш без причины — строка «Причина не указана». Медиана «создание → первый
   снимок» — в днях по проектам периода, у которых есть снимок (GAP-05).
5. **Деньги.** `portfolio.read` даёт деньги всех проектов (R-02), поэтому членство не
   проверяется; чтение — новой функцией сервиса денег `portfolio_money` (G-11). TOTP — gate.
   Аудит первого открытия чужого проекта за сессию уже делает авторизатор (SEC-005); добавлен
   тест «повторное открытие — без второй записи».

## Последствия

  статуса и модератора, нужна правка контракта (CR).
