# DEC-20261110-adm-replace

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-10T15:30:00Z
- **Трек:** ADM (ADM-012); потребители — FE-071, QA-015
- **Основание:** SPEC FR-ADM-05, Q-29, TC-ADM-01, G-20; 15.2 `POST /admin/users/{id}/replace`;
  contracts/openapi.yaml `ReplaceRequest`, `ReplaceReport`

## Решение

1. **Общий код с заменой в одном проекте.** `services.team.transfer` переносит строки исходного
   (роль, дисциплина, ревьюерство), исключает его, переадресует открытые адресованные ему вопросы
   с событием в ленте и шлёт `question_redirected` замене и `member_replaced` модераторам и
   замене. Замена в своём проекте (CORE-012) теперь тоже переадресует вопросы.
2. **Dry run по умолчанию.** Список — проекты исходного не в «Архиве»; по каждому роли, число
   открытых вопросов ему и `applicable`/`problem` (`replacement_lacks_moderator_role`,
   `replacement_lacks_presale_role`). Проверка ролей та же, что в одном проекте.
3. **Подтверждение.** `project_ids` — отмеченные строки; проект не из списка — 422, неприменимая
   строка пропускается без ошибки и считается в аудите `projects_skipped`. Ответ — тот же отчёт с
   `applied: true`.
4. **Замена.** Совпадает с исходным, заблокирована, обезличена или с ролью без проектов — 422.
   Исходный пользователь не обязан быть заблокирован («обычно заблокированного» в FR-ADM-05).
5. **Аудит** `users.replaced_everywhere` с числами применённых, пропущенных проектов и
   переадресованных вопросов; изменения команды пишутся по каждому проекту как обычно.
