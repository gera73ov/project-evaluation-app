# DEC-20261109-core-review

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-09T17:40:00Z
- **Трек:** CORE (CORE-019, снятие «Проверено» из CORE-018); потребители — FE-029, CORE-016, CORE-017, статистика FR-REV-03
- **Основание:** SPEC FR-REV-01, FR-REV-02, FR-REV-04, Q-33, BR-BR-02; contracts/openapi.yaml (`reviewNode`)

## Решение

1. **Отметка узла** ставится (снимается) на самом узле и на всех живых узлах поддерева, включая
   промежуточные: по таблице BR-BR-02 отметку несут и узлы-предки. Ветку дисциплины отмечать можно,
   строку фазы — нет (422).
2. **Повторная отметка** уже отмеченного узла ничего не меняет: автор и время прежние, событий нет.
3. **Самопроверка** — только у листа: ревьюер — автор последней записи истории листа с O, R, P или ×N
   (включая создание с оценкой). Участник с ролью модератора проекта самопроверку не получает.
4. **История и события:** каждый изменённый узел — запись `review` (`{"review": [было, стало]}`, при
   самопроверке ещё `self_review`), `field_versions.review` и `node.updated` с `changed_fields: ["review"]`
   со своей версией проекта.
5. **Снятие при правке** (BR-BR-02): правка O/R/P/×N снимает отметку с листа в той же версии, что и
   правка, и отдельными событиями — со всех предков; добавление узла — с родителя и всех предков.
   Удаление, восстановление, разбиение, сворачивание и перенос подключат CORE-016/CORE-017 через
   `services.review.marks.clear`.
