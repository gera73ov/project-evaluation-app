# DEC-20261110-core-stats

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-10T14:10:00Z
- **Трек:** CORE (CORE-050, CORE-051, CORE-053); потребители — FE-040…043, FE-093, EXP-009, QA-017
- **Основание:** SPEC 10.1, 11.8–11.11, BR-PRJ-08, BR-TREE-09, FR-REV-03, FR-NOTIF-03, GAP-08;
  contracts/openapi.yaml `Stats`, `RemindResult`, errors.yaml `REMIND_TOO_OFTEN`,
  notifications.yaml `remind_not_started`

## Решение

1. **Один ответ `GET /projects/{id}/stats`** по контракту `Stats`. Обсуждения, вопросы
   заказчику и список снимков в нём нет — у них свои эндпоинты; вкладки статистики берут их там.
2. **Сетка готовности.** Ячейки — включённые фазы работ × дисциплины проекта. Нет строки статуса —
   «не начато». «Последняя правка» — позднее из правки листьев ветки и смены статуса.
   `open_question` — открытое обсуждение (любое, не только вопрос заказчику) на узле ветки.
   `overdue` — дедлайн прошёл, ветка не «готово» и не «не нужно»; `overdue_working_days` —
   рабочие дни после дедлайна по календарю. Флажка «N не учтены» в контракте нет — интерфейс
   берёт его из дерева.
3. **«Проверено».** Обе доли — от E дисциплины: доля E листьев с отметкой и доля E листьев с
   самопроверкой; у дисциплины без часов — `null`.
4. **Доли и проценты** — один знак, ROUND_HALF_UP. Стоимость по фазе — сумма по ячейкам
   «E × ставка» с округлением ячейки; не хватает ставки при E > 0 — `null`.
5. **Динамика** читает `project_totals_daily` (заполнение — CORE-052, пока ряд пуст).
6. **«Напомнить не начавшим».** Адресаты — эксперты дисциплин, у которых хотя бы одна ветка
   включённой фазы работ «не начато»; модератор себе не пишет. Без адресатов — `sent_to: 0`, сутки
   не начинаются. Ограничение — ключ Redis на 24 часа; повтор — 429 `REMIND_TOO_OFTEN` с
   `Retry-After`. Дедлайн в письме — ДД.ММ.ГГГГ. Признака «есть адресаты» в контракте нет —
   интерфейс видит его по сетке (ячейки «не начато» без `no_expert`).
