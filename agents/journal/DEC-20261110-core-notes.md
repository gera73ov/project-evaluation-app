# DEC-20261110-core-notes

- **Тип:** решение (DEC), уровень A1
- **Время:** 2026-11-10T14:30:00Z
- **Трек:** CORE (CORE-031). Потребители: FE-092 (вкладка «🔒 Заметки»), QA-007 (TC-SEC-07).
- **Основание:** SPEC FR-NOTE-01, Q-03, FR-2FA-05, SEC-AUTHZ-04, 11.4 №18; contracts/openapi.yaml
  (`listNotes`, `createNote`, `patchNote`), permissions.yaml (M3.3-32, D-01, M3.4-13),
  ws-events `note.created`/`note.updated`.

## Решение

1. **Код:** `services/notes/service.py` (список, создание, правка), `api/v1/notes.py`, резолвер
   `/notes/{id}` (проект и статус заметки).
2. **Кто:** только gate по `notes.read`/`notes.write` с `totp_gate`.
   - Модераторы и пресейл проекта читают и пишут; руководитель пресейла только читает.
   - Эксперты и ревьюеры → 403 `FORBIDDEN`; без TOTP в сессии → 403 `TOTP_REQUIRED`.
   - В «Завершена» и «Архиве» писать нельзя (D-01, 409 `PROJECT_STATUS_CONFLICT`), читать можно.
3. **Править может любой держатель `notes.write`**, не только автор: у права в permissions.yaml
   нет `scope: author`, SPEC автора не выделяет. Автор заметки не меняется, `edited_at` — время
   правки. Правка тем же текстом ничего не пишет.
4. **Текст** хранится как введён, пустой или из пробелов → 422 `VALIDATION_FAILED`; `node_id`
   должен быть живым узлом этого проекта, иначе 422.
5. **Список:** по времени создания (старые сверху, как лента), курсор `(created_at, id)`, фильтр
   `node_id`; без фильтра — все заметки проекта и узлов.
6. **События** `note.created`/`note.updated` — только в `project:{id}:notes`, с текущей версией
   проекта без её увеличения (дерево не меняется, как `money.updated`). В `change_log`, журнал
   проекта, ленты обсуждений, счётчики дерева, экспорт и снимки заметки не попадают; счётчика
   заметок в API нет.
