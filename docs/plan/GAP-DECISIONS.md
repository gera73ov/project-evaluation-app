# Решения по пробелам плана (GAP-01…GAP-12)

Разбор с Marrmon, начат 04.11.2026. Решения вносятся в PLAN.md (раздел 11.2, колонка «Решение») и внесены в SPEC v0.5 (04.11.2026, пометки «[Решение GAP-NN]», сводка — раздел 19 SPEC).

| № | Решение | Дата |
|---|---|---|
| GAP-01 | Новая таблица `project_totals_daily` (project_id, date, E, P80, P90, деньги как в `project_totals`); задача кэша итогов перезаписывает строку текущего дня. Деньги отдаются только с `money.read`. | 04.11.2026 |
| GAP-09 | Сертификат SIEM проверяется по загружаемому CA и имени хоста (обязательно); клиентский сертификат (mTLS) — опционально в настройках. | 04.11.2026 |
| GAP-12 | `project purge` требует номер заявки и логин согласовавшего сотрудника ИБ; сначала dry-run с составом удаляемого, затем подтверждение вводом id проекта; всё пишется в аудит и SIEM. | 04.11.2026 |
| GAP-06 | Документы из корзины восстанавливают модератор и пресейл проекта (те же, кто удаляет); остальные удалённые документы в корзине не видят; восстановление пишется в аудит. | 04.11.2026 |
| GAP-02 | Пути дописываются в OpenAPI (API-002) по соглашениям 15.1 с пометкой `x-spec-gap: GAP-02`, права по 3.3: `GET /projects/{id}/journal`, `POST /documents/{id}/restore`, `GET /projects/{id}/stats/{tab}/export?format=xlsx`, `GET /projects/{id}/assumptions/export`, `GET /projects/{id}/members/suggest?q=`. | 04.11.2026 |
| GAP-04 | «Увидел правку» = уведомление о правке модератора открыто (`read_at`) не позже 7 дней; «время до первого листа» = от первого успешного входа эксперта (аудит) до первого листа с O/R/P в `node_history`. Считает отчёт PM-006. | 04.11.2026 |
| GAP-05 | Медиана «создание проекта → первый снимок» — плашка в сводке портфеля руководителя пресейла (10.4) за выбранный период, плюс строка в отчёте пилота PM-006. | 04.11.2026 |
| GAP-08 | «Просрочено» — флажок ⏰ «просрочено на N раб. дн.» в неготовых ячейках сетки готовности (11.8) после дедлайна; рабочие дни по BR-PRJ-08. | 04.11.2026 |
| GAP-10 | Предупреждение — до сохранения: перед первой правкой готовой ветки в «Сведении» диалог «Ветка вернётся в черновик. Продолжить?»; после подтверждения дальнейшие правки в этой ветке без вопросов. | 04.11.2026 |
| GAP-03 | Принимается CSV производственного календаря в формате открытых данных data.gov.ru (Минтруд) без правок; перед сохранением — предпросмотр по месяцам; точечные правки — вручную (7.5). | 04.11.2026 |
| GAP-07 | Курируемый набор ~30 иконок: 10 из 5.2 и около 20 из той же библиотеки фронтенда, зашиты в код; выбор сеткой в диалоге; загрузка своих файлов не поддерживается. | 04.11.2026 |
| GAP-11 | Спецификацию не меняем; план ссылается на FR-DOC-01 и 11.7; замена «8.6» → «FR-DOC-01» в 1.4 и 1.5 внесена в список правок для SPEC v0.5. | 04.11.2026 |
