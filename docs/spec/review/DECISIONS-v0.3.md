# Решения по вопросам ревью v0.3 (R-01…R-10)

Журнал ответов Marrmon по REVIEW-v0.3.md. Вносятся в SPEC.md при выпуске версии 0.4 вместе с дефектами C-01…C-33 и M-01…M-18.

| № | Дата | Решение |
|---|---|---|
| R-01 | 04.11.2026 | Экспорт для КП: каждая строка = округл(стоимость_E · P80/E) (или P90/E), итог КП = сумма скорректированных строк; формулу итога P80/P90 в 6.4 заменить на «сумма строк» |
| R-02 | 04.11.2026 | Открытие чужого проекта руководителем пресейла пишется в аудит (первое открытие проекта за сессию); модераторы не уведомляются |
| R-03 | 04.11.2026 | Комментарий листа многострочный, у каждой строки своя метка (Огр./Тех./Риск/Допущение или без метки); в строке дерева видна первая строка и «+N»; `comment_tag_id` заменить метками по строкам |
| R-04 | 04.11.2026 | Учётке AD без группы доступа (и при любом другом отказе) показывается единый текст: «Неверный логин или пароль. Если уверены в пароле — обратитесь к администратору»; причина только в аудите. FR-AUTH-AD-05 привести к FR-AUTH-AD-13 |
| R-05 | 04.11.2026 | Обязательность TOTP — переключатель по системным ролям, применяется со следующего входа; дополнительно эндпоинты денег (`money.*`) и закрытых заметок (`notes.*`) недоступны, пока в текущей сессии не пройден TOTP |
| R-06 | 04.11.2026 | Руководитель пресейла «Становится модератором» только сам, в любом статусе проекта, кроме «Архив»; передавать проект и добавлять других модераторов не может. Выровнять матрицу 3.3, FR-PORT-03, 11.13 |
| R-07 | 04.11.2026 | Блокировка после 5 неудачных попыток — по паре «логин + IP» на 15 минут; владелец с другого IP входит. Лимит 20 попыток в минуту с IP (FR-LOCK-02) сохраняется |
| R-08 | 04.11.2026 | По наведению на Σ E узла — подсказка ΣO/ΣR/ΣP, σ, P80 (без долей); доли только в статистике |
| R-09 | 04.11.2026 | В дереве комментарий листа занимает до 2 строк, дальше «…» с раскрытием по клику (с учётом R-03: первая строка-метка + «+N»); концепцию поправить |
| R-10 | 04.11.2026 | Квартальная проверка восстановления — на рабочем ключе; запечатанную копию из сейфа ИБ проверяют раз в год при ротации ключа, перед заменой (акт вскрытия) |
| C-05 | 04.11.2026 | Отвеченный вопрос заказчику закрывают автор вопроса, модератор или пресейл (как в диаграмме 4.4); выровнять FR-DISC-05, матрицу 3.3 и 15.2 |
| C-27 | 04.11.2026 | Порог «крупного листа» (80 ч) сравнивается с E одной штуки; лист ×N > 1 с большим итогом помечается «повторяющийся» |
| C-31 | 04.11.2026 | Ставка НДС нового проекта берётся из настройки администратора «НДС по умолчанию» (справочник ставок дополняется 22%, по умолчанию 22%); добавить настройку в 7.5 |
| C-13 | 04.11.2026 | Неоднозначные совпадения при переходе «Приложение» → AD подтверждает суперадминистратор (уточнение Q-20); везде в тексте заменить «администратор» на «суперадминистратор» |
